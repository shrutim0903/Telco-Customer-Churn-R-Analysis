# Telco Customer Churn Analysis using R

## Project Overview

This project analyzes customer churn using R. The analysis covers data
cleaning, missing value handling, outlier detection, data transformation,
exploratory data analysis, visualization, statistical hypothesis testing,
and predictive modeling.

## Dataset

The project uses the Telco Customer Churn dataset containing 7,043
customer records and 21 variables.

## Analysis Performed

- Data cleaning and preprocessing
- Missing value analysis
- Outlier detection using IQR
- Numerical feature normalization
- Categorical variable encoding
- Exploratory data analysis
- Correlation analysis
- Data visualization
- Chi-square hypothesis testing
- Logistic regression
- Confusion matrix evaluation
- ROC-AUC analysis
- 5-fold cross-validation

## Key Results

- Customer churn rate: 26.54%
- Logistic regression test accuracy: approximately 81.12%
- ROC-AUC: 0.8521
- 5-fold cross-validation accuracy: 79.09%

## Tools Used

- R
- RStudio
- Base R
- Statistical modeling
- Data visualization
